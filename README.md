# Installer le projet
Clonez le dépôt sur votre machine locale via la commande :

```
git clone git@github.com:LaureEverwyn/Motus.git
```

# Utiliser le jeu

1. Ouvrir **index.html**
2. Ecrire le premier mot
3. Appuyer sur le bouton **Valider** ou sur **Entrée** 
4. Le jeu vous dira si le mot est trouvé ou non 
5. Dès que la partie est terminée, cliquez sur le bouton **Nouvelle partie** pour rejouer.

## Légende 

- Si la case est <u>verte</u> : la lettre est bonne et bien placé

- Si la case est <u>orange</u> : la lettre est bonne mais mal placé

- Si la case est <u>grise</u> : la lettre n'est pas dans le mot à trouver
